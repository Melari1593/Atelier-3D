# Atelier 3D

Prototipo de una página web para explorar conceptos de piezas imprimibles en 3D.

## Funciones

- Vistas conceptuales de figura articulada, llavero, molde negativo, conectores y placa.
- Ajuste de ancho, alto, grosor, color, texto, acabado, conector y orificio.
- Imagen de referencia procesada solamente en el navegador.
- Guardado local de la configuración con `localStorage`.
- Exportación de una **base rectangular STL** con las dimensiones indicadas, como punto de partida para CAD. Los detalles de la vista previa no se incorporan a ese archivo.

## Ejecutar

Abre `dist/index.html` en un navegador moderno. No necesita instalación ni servidor.

## Estado

Este es un prototipo de interfaz. Antes de imprimir una pieza, termina su geometría en CAD y revisa malla, tolerancias y resistencia en el laminador.
